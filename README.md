# 🧮 Simple Windows Forms Calculator

A lightweight, user-friendly desktop calculator built with **C#** and **Windows Forms** as a backend and desktop development practice project. It features dynamic expression evaluation, supporting consecutive operators and standard mathematical order of operations.

---

## ✨ Features

- **Smart Expression Evaluation:** Handles arbitrary sequences of arithmetic operations (e.g., `4 * 5 - 6`) dynamically using `DataTable.Compute`.
- **Mathematical Precedence:** Automatically respects standard operator priority (multiplication/division before addition/subtraction).
- **Input Validation:** Built-in safeguards to prevent multiple consecutive decimal points or invalid formats.
- **User-Friendly Interface:** Clean layout designed via Visual Studio Windows Forms Designer.

---

- **Language:** C# (.NET Framework)
